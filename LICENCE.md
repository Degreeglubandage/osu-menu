## 🧩 About

**osu! Menu** is a comprehensive menu overlay for osu! featuring a beatmap browser, mod switcher, skin reloader, score tracker, quick restart, and per-map settings.

Based on popular osu! tools and menus like **osu!lazer**, **McOsu**, and community overlay projects.

---

## ✨ Features

### 🎮 Core Menu
- Beatmap Browser — search and load maps without leaving the game
- Mod Switcher — toggle mods quickly from the overlay
- Quick Restart — restart the current map with one key
- Score Tracker — live accuracy, combo, and pp estimate
- Replay Controls — jump to any point of a replay

### 🎨 Cosmetics & Skins
- Skin Reloader — reload skin files without restarting
- Cursor Customizer — change cursor size, trail, and color
- Hit Sound Preview — audition hitsounds in the menu
- Background Blur — adjustable blur for menu readability

### 🏋️ Practice & Training
- Section Looper — loop any segment of a beatmap
- Playback Speed — adjust map speed for practice
- Aim Trainer Overlay — warm up with custom patterns
- Offset Helper — fine-tune local offset before playing
